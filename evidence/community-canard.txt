Keyboard Size and Schematic Done | Canard70

Hey there! New week, new project! This week I'm working on Canard70, a compact 65%-style keyboard with some extra touches including a split spacebar. I first spent about an hour researching and figuring out the layout and size, as well as the number of keys and how I'll map it. I changed my mind and added a number row, taking it from 55 to 70 keys! Therefore I'm using a 6x12 matrix instead of a 5x14 like it actually is.

I then mapped out exactly how my wiring path for the matrix would look like (because it is 6x12) and also chose my mappings on the nice_nano accordingly. Finally I added the switch matrix into my schematic.

Lastly I added the Nice!nano and the supporting battery circuit, rounding off my schematic. I will add a reset button, mounting holes, and stabilizers as needed later.

See y'all in the next one!
